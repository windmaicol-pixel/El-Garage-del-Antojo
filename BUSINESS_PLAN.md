## 💰 Estrategia de Precios

### **Estructura de Costos:**
```
Costo de ingredientes: 30-40% del precio
Envío prorrateado: $5 por producto
Utilidad: 50-60%
```

### **Ejemplo Papas Clásicas Grandes:**
```
Costo ingredientes: $25
Envío incluido: $5
Utilidad: $40
────────────────────
Precio final: $70 ✅

Margen: 57%
```

### **Por qué incluir envío en precio:**
✅ Psicología: "Envío gratis" aumenta conversión 20-30%  
✅ Simplicidad: Sin cálculos complicados  
✅ Marketing: Ventaja competitiva clara  
✅ Sin reclamos: Todos pagan igual (justo si están cerca)

### **Semana 1: Soft Launch**

## 🔄 Flujo Operativo

### **Opción A: Cliente pide por WhatsApp**
```
1. Cliente manda mensaje con pedido
2. Tú lo anotas
3. Abres app admin → "Crear Pedido Manual"
4. Buscas/registras cliente
5. Agregas productos
6. Guardas pedido
7. Sistema te notifica cuando esté listo para entregar
8. Entregas y cobras
```

### **Opción B: Cliente pide por app (ideal)**
```
1. Cliente abre app → Menú
2. Agrega productos al carrito
3. Checkout → Selecciona método de pago
4. Confirma pedido
5. TÚ recibes notificación push inmediata 🔔
6. Ves pedido en dashboard admin
7. Cambias status: Confirmado → Preparando → En Camino
8. Entregas y cobras según método elegido
9. Marcas como "Entregado"
```

## 💳 Métodos de Pago

### **1. Efectivo**
- Cliente indica si necesita cambio
- Especifica con cuánto pagará
- Repartidor lleva cambio calculado
- Paga al recibir

### **2. Transferencia Bancaria**
- Se muestran datos de cuenta
- Cliente hace transferencia ANTES
- Envía comprobante por WhatsApp
- Se verifica y entrega

### **3. Tarjeta (Terminal del repartidor)**
- Repartidor lleva terminal
- Cliente paga al recibir
- Entrega después de pago exitoso

**Importante**: Ningún pago se procesa en línea dentro de la app.
